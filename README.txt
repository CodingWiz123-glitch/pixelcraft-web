PIXELCRAFT WEB PORTFOLIO STARTER

1. Open this folder in Visual Studio Code.
2. Open index.html in your browser to preview it.
3. Edit index.html for words and sections, style.css for appearance, and script.js for interactions.
4. Before publishing, replace the sample email link with a parent-approved contact method.
5. The three project cards are concepts. Keep them labelled as sample/concept work until you have real client projects.

No frameworks or paid tools are required for this starter project.
